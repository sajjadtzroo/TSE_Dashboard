## 🔄 Application Process

```mermaid
flowchart LR
    A[1. نصب اپلیکیشن] --> B[2. افتتاح حساب]
    B --> C[3. افزایش موجودی]
    C --> D[4. کسب امتیاز]
    D --> E[5. درخواست وام]
    E --> F[6. اعتبارسنجی آنلاین]
    F --> G[7. امضای دیجیتال]
    G --> H[8. واریز آنی]
```

### Step by Step (فارسی)

1. **نصب اپلیکیشن** و افتتاح حساب
2. **افزایش موجودی** برای کسب امتیاز
3. مراجعه به بخش **"وامینو"** در اپلیکیشن
4. **درخواست وام** و انجام اعتبارسنجی آنلاین
5. **امضای دیجیتال** قرارداد
6. **واریز آنی** وجه به حساب
